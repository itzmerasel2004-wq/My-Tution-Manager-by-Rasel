🛡️ Backup & Recovery

BackupCompactNo saved receipt files
SecuritySHA-256When supported

Backup keeps student/payment history, routines, teaching records, schedules, tasks and teacher profile. Payment receipts are NOT stored as files; they are generated from payment data whenever needed. Password is never exported.

📦 App-only sharing

Downloads only the HTML application. Current local backup data is not included.

🧪 Data integrity

Backups contain a SHA-256 checksum when browser crypto is available. Invalid/corrupted backups are rejected.
